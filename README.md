# HERMES

HERMES is a private, personal automation tool used only by its owner
to organize the owner's own Google Drive files. It is not offered to
the public.

## Privacy Policy

HERMES accesses Google Drive and Google Sheets data only for the
owner's own account, only to read, organize, and store the owner's
files. No data is sold, shared with third parties, or used for
advertising. Data stays in the owner's Google account and on the
owner's private server. Access can be revoked at any time at
https://myaccount.google.com/permissions.
